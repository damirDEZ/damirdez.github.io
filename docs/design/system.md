# Дизайн-система

Собрана 24.11 из одобренного макета главной (Дамир 24.11: «Да, делаем так»).
Токены: `docs/design/tokens.css` (после T-002 — `src/styles/tokens.css`). Витрина: `system.html`, снимок `system-1280.png`.
Новый экран — только на этой системе. Нужен компонент, которого нет, — сначала добавь его сюда.

## Характер

Тёмный, «киношный»: работы — главные, интерфейс тихий. Один акцент — оранжевый; он же метка ИИ.
Одна тема — тёмная, светлой нет (решение 24.11).

## Цвета

| Токен | Значение | Для чего |
|---|---|---|
| `--bg` | #0a0a0c | фон страницы |
| `--surface` / `--surface-2` | #131317 / #1b1b21 | карточки / заглушки, иконки |
| `--line` / `--line-strong` | #26262e / #3a3a45 | рамки / рамка при наведении |
| `--text` / `--text-2` | #f3f1ec / #a4a3ad | основной / вторичный текст |
| `--accent` (+ hover, pressed) | #ff8a3d | главная кнопка, метки ИИ, номера разделов |
| `--accent-ink` | #160b03 | текст на акценте |
| `--success` / `--warning` / `--error` | #5fd19b / #f2c14e / #ff5d5d | Live / предупреждение / ошибка |

Контраст текста к фону — не ниже 4.5:1 (фактически 6.6–17.6:1). Акцент не используем для длинного текста.

## Типографика

- Заголовки — Space Grotesk 600, межбуквенный −0.02em, межстрочный 1.05. Текст — Inter 400/500/600, межстрочный 1.6.
- H1 40→84px, H2 32→56px, H3 22px (в кейсе 28→40px), лид 17→20px, текст 16px, мелкий 15px.
- Подпись раздела (eyebrow) — 13–14px, ЗАГЛАВНЫЕ, разрядка 0.12em; номер раздела — акцентом («01 — Video»).

## Отступы и сетка

- Шаг 4px: 4, 8, 12, 16, 24, 32, 40, 56, 72. Между разделами — 72→128px, разделы делит тонкая линия.
- Контейнер 1360px по центру, поля 16→48px. Фоновые свечения (первый экран, контакт) — на всю ширину, чтобы на 1920 не было пустых полос.
- Скругления: 10 (мелкие кадры), 18 (карточки, кадры), 24 (кейс), 28 (контакт), пилюля (кнопки, метки). Теней нет — глубину дают поверхности и рамки.
- Раскладка: **≤640** — одна колонка, кнопки на всю ширину; **≤1020** — две колонки, меню в кнопку; **>1020** — как в макете (3 колонки, первая работа крупно).

## Компоненты

У каждого — состояния: обычное, наведение, нажатие, выключено (где применимо).

- **Кнопка главная** — акцентная пилюля 48px (малая 38px). Наведение — светлее, нажатие — темнее и сжатие 0.98, выключено — `--surface-2`, текст `--text-2`, без курсора.
- **Кнопка вторичная** — пилюля с рамкой на `--surface`. Наведение — `--line-strong`.
- **Опасная кнопка** — не нужна: на сайте нет удаления.
- **Метка (chip)** — обычная (серая рамка), **ИИ** (оранжевая рамка и текст), **фильтр активный** (заливка `--text`, текст `--bg`).
- **Кадр** — 16:9 (в избранном 4:3), виньетка; поверх: кнопка Play, длительность справа внизу, бейдж слева сверху («Live» с зелёной точкой, «In development»).
- **Карточка работы** — кадр, тип работы, заголовок H3, строка описания, метки.
- **Кейс** — поверхность 24px: окно браузера со снимком + Task / What we did / Result + метки + кнопки.
- **Список «сделано / дальше»** (devlog) — строки с линией; «Next» — акцентом.
- **Карточка инструмента** — иконка-монограмма, название, строка «для чего».
- **Обложка-превью** — кадр с крупным заголовком ЗАГЛАВНЫМИ.
- **Шапка** — липкая, полупрозрачная с размытием: логотип «DAMIR.», разделы, «Hire me». ≤1020 — разделы прячутся в кнопку меню.
- **Блок контакта** — поверхность 28px со свечением, крупный заголовок, Telegram + почта, адрес почты текстом.
- **Поля ввода** — не нужны: формы нет (решение 24.11).
- **Пустое состояние** — раздел без работ не показывается; внутри кейса без картинки — кадр-заглушка с подписью «Coming soon».
- **Загрузка** — кадр-скелет `--surface-2` с мягким переливом.
- **Ошибка** — видео не загрузилось: кадр с текстом «Video unavailable» и ссылкой «Watch on YouTube ↗».

## Тон текстов

- Английский, от первого лица («I edit…», «we built…» для командных работ).
- Коротко: заголовок — до 6 слов, описание работы — одна строка.
- Уверенно, без хвастовства и пустых слов («passionate», «guru», «synergy» — нет).
- Только правда: цифры, сроки и обещания — лишь подтверждённые Дамиром.
