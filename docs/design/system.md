# Дизайн-система

Собрана 24.11 из одобренного макета главной (Дамир 24.11: «Да, делаем так»).
Токены: `src/styles/tokens.css` (перенесены из `docs/design/` в T-002; витрина подключает их оттуда). Витрина: `system.html`, снимок `system-1280.png`.
Новый экран — только на этой системе. Нужен компонент, которого нет, — сначала добавь его сюда.

## Характер

Тёмный, «киношный»: работы — главные, интерфейс тихий. Один акцент — оранжевый; он же метка ИИ.
Одна тема — тёмная, светлой нет (решение 24.11).

## Цвета

| Токен | Значение | Для чего |
|---|---|---|
| `--bg` | #0a0a0c | фон страницы |
| `--surface` / `--surface-2` | #131317 / #1b1b21 | карточки / заглушки, иконки |
| `--line` / `--line-strong` | #26262e / #3a3a45 | рамки / рамка при наведении |
| `--text` / `--text-2` | #f3f1ec / #a4a3ad | основной / вторичный текст |
| `--accent` (+ hover, pressed) | #ff8a3d | главная кнопка, метки ИИ, номера разделов |
| `--accent-ink` | #160b03 | текст на акценте |
| `--success` / `--warning` / `--error` | #5fd19b / #f2c14e / #ff5d5d | Live / предупреждение / ошибка |

Контраст текста к фону — не ниже 4.5:1 (фактически 6.6–17.6:1). Акцент не используем для длинного текста.

## Типографика

- Заголовки — Space Grotesk 600, межбуквенный −0.02em, межстрочный 1.05. Текст — Inter 400/500/600, межстрочный 1.6.
- H1 40→84px, H2 32→56px, H3 22px (в кейсе 28→40px), лид 17→20px, текст 16px, мелкий 15px.
- Подпись раздела (eyebrow) — 13–14px, ЗАГЛАВНЫЕ, разрядка 0.12em; номер раздела — акцентом («01 — Video»).

## Отступы и сетка

- Шаг 4px: 4, 8, 12, 16, 24, 32, 40, 56, 72. Между разделами — 72→128px, разделы делит тонкая линия.
- Контейнер 1360px по центру, поля 16→48px. Фоновые свечения (первый экран, контакт) — на всю ширину, чтобы на 1920 не было пустых полос.
- Скругления: 10 (мелкие кадры), 18 (карточки, кадры), 24 (кейс), 28 (контакт), пилюля (кнопки, метки). Теней нет — глубину дают поверхности и рамки.
- Раскладка: **≤640** — одна колонка, кнопки на всю ширину; **≤1020** — две колонки, меню в кнопку; **>1020** — как в макете (3 колонки, первая работа крупно).

## Компоненты

У каждого — состояния: обычное, наведение, нажатие, выключено (где применимо).

- **Кнопка главная** — акцентная пилюля 48px (малая 38px). Наведение — светлее, нажатие — темнее и сжатие 0.98, выключено — `--surface-2`, текст `--text-2`, без курсора.
- **Кнопка вторичная** — пилюля с рамкой на `--surface`. Наведение — `--line-strong`.
- **Опасная кнопка** — не нужна: на сайте нет удаления.
- **Метка (chip)** — обычная (серая рамка), **ИИ** (оранжевая рамка и текст), **фильтр активный** (заливка `--text`, текст `--bg`).
- **Кадр** — 16:9 (в избранном 4:3), виньетка; поверх: кнопка Play, длительность справа внизу, бейдж слева сверху («Live» с зелёной точкой, «In development»). Кнопка Play везде одна: 64px, ≤640 — 52px (решение менеджера 25.11; в макете кейса было 56). Градиенты-заглушки: g1…g7, плюс g3b, g3c (оттенки g3 для галереи кейса).
- **Карточка работы** — кадр, тип работы, заголовок H3, строка описания, метки.
- **Кейс** — поверхность 24px: окно браузера со снимком + Task / What we did / Result + метки + кнопки.
- **Список «сделано / дальше»** (devlog) — строки с линией; «Next» — акцентом.
- **Карточка инструмента** — иконка-монограмма, название, строка «для чего».
- **Обложка-превью** — кадр с крупным заголовком ЗАГЛАВНЫМИ.
- **Шапка** — липкая, полупрозрачная с размытием: логотип «DAMIR.», разделы, «Hire me». ≤1020 — разделы прячутся в кнопку меню.
- **Меню (открыто)** — ≤1020px: выпадающая панель под шапкой на сплошном `--bg`, пункты Space Grotesk 20px с линиями `--line` между ними; кнопка меню превращается в крестик. Закрывается крестиком, пунктом, Escape, кликом мимо. (Принято менеджером 25.11 по итогам T-002; снимок — `npm run shots` → `home-390-menu.png`.)
- **Отступ под шапку** — при переходе по якорю заголовок раздела не прячется под липкой шапкой (`scroll-padding-top` = высота шапки: 72px, ≤640 — 64px; плюс линия 1px).
- **Сетка избранного** — первая работа крупно (кадр 4:3, на две строки), две справа; ≤1020 — первая на всю ширину, ≤640 — одна колонка.
- **Строка инструментов** («Daily tools») — вторичный текст, названия инструментов основным цветом, в одну строку с переносом.
- **Подпись под кадром** (шоурил) — строка вторичного текста: слева название, справа ссылка «Watch ↗» (только если есть ссылка).
- **Полоса «в работе»** — пунктирная рамка `--line-strong`, акцентная точка, жирное начало фразы, справа год; для проектов без кейса.
- **Пункт «How I work»** — линия сверху, заголовок Space Grotesk 20px, строка вторичного текста; три в ряд, ≤640 — столбиком.

### Страница кейса (макет `docs/design/case/`, одобрен Дамиром 25.11)

- **Ссылка назад** — «← All work», вторичный текст 14px, наведение — основной цвет; ведёт к избранному на главной.
- **Шапка кейса** — eyebrow (тип работы), H1 44→104px, лид; справа главная кнопка «Visit live site ↗» / «Watch ↗» (только если есть ссылка; ≤640 — на всю ширину); мягкое свечение в цвет обложки.
- **Мета-строка** — 4 ячейки между двумя линиями: подпись 13px вторичным, значение Space Grotesk 18px; ≤1020 — 2×2. Пустое значение — ячейки нет.
- **Обложка** — окно браузера (сайты) или кадр с плеером (видео), 16:8.5, ≤640 — 4:3.
- **Глава** — слева номер акцентом («01 — Task»), справа H2 28→40px и текст 17px вторичным, колонка до 680px; ≤1020 — номер над текстом.
- **Шаги** — нумерованный список в две колонки с линиями, номер акцентом; ≤640 — одна колонка.
- **Выноска «How AI helped»** — поверхность 24px с оранжевой рамкой и свечением, иконка «AI», заголовок 20px, текст, метки инструментов.
- **Кадр телефона** — рамка 28px на `--surface` с вырезом сверху, экран 9:19; в галерее чередуется с окнами браузера (окно — 2 колонки из 3, телефон — 1).
- **Галерея из одних кадров** (ролики, без телефонов) — две равные колонки 16:9, нечётный последний — на всю ширину; ≤640 — одна колонка (решение менеджера 25.11).
- **Карточка «Next work»** — поверхность 24px: слева eyebrow, заголовок, строка, метки, «View case →» акцентом; справа кадр; ≤1020 — кадр под текстом.
- **Контакт в кейсе** — блок контакта компактнее главной (заголовок 34→64px против 36→80px, как в одобренном макете кейса), заголовок под тип работы: «Want a site like this?», «Want a video like this?», для игры — «Want to work together?».
- **Блок контакта** — поверхность 28px со свечением, крупный заголовок, Telegram + почта, адрес почты текстом.
- **Поля ввода** — не нужны: формы нет (решение 24.11).
- **Пустое состояние** — раздел без работ не показывается (и его пункт в меню); нет ссылки — нет кнопки; нет картинки — градиент-заглушка с подписью, что должно быть на кадре (как в макете; решение менеджера 25.11). «Coming soon» — только для проекта, у которого ещё нет кейса (полоса «в работе»).
- **Загрузка** — кадр-скелет `--surface-2` с мягким переливом.
- **Ошибка** — видео не загрузилось: кадр с текстом «Video unavailable» и ссылкой «Watch on YouTube ↗».

## Тон текстов

- Английский, от первого лица («I edit…», «we built…» для командных работ).
- Коротко: заголовок — до 6 слов, описание работы — одна строка.
- Уверенно, без хвастовства и пустых слов («passionate», «guru», «synergy» — нет).
- Только правда: цифры, сроки и обещания — лишь подтверждённые Дамиром.
