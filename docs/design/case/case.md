# Макет: страница кейса (на примере Go Fashion)

Задача: T-004. Файлы: `case.html` — макет; снимки `case-390.png`, `case-1280.png`, `case-1920.png`.
Строится на дизайн-системе; новые компоненты — в `docs/design/system.md`, раздел «Страница кейса».
Картинки — заглушки-градиенты; цифры в мета-строке (команда, срок) и тексты — выдуманные, заменим словами Дамира.

## Как это работает

- **Кто и где видит:** посетитель нажимает на работу на главной (Selected work, Websites, Video) — открывается её страница по своему адресу (например `/work/go-fashion`).
- **Сверху вниз:** «← All work» → тип работы, название, одна строка, кнопка «Visit live site ↗» → мета-строка (роль, команда, срок, год) → большая обложка → главы «Task / What we did / Result» → выноска «How AI helped» → галерея экранов (компьютер и телефон) → «Next work» → блок «Want a site like this?» с Telegram и почтой.
- **Один шаблон для всех работ.** У сайта обложка — окно браузера, у ролика — плеер; заголовок контакта под тип работы («Want a video like this?»).
- **Пустые поля:** нет ссылки — нет кнопки; нет значения в мета-строке — ячейки нет; нет скриншотов — нет галереи; нет ИИ в работе — нет выноски. Страница не ломается.
- **Много скриншотов:** галерея растёт рядами «окно + телефон», чередуя стороны; больше 8 — показываем 8.
- **«Next work»** — следующая работа по порядку на главной; у последней — первая.
- **Не делаем:** комментарии, лайки, счётчики просмотров, отдельные языки, фильтры по работам.

## Что нужно от Дамира для настоящего кейса Go Fashion

Ссылка на сайт; 3–5 скриншотов (компьютер и телефон); своими словами — какая была задача, что делал ты и что команда, сколько человек и сколько времени заняло, как помог ИИ.
