# Макет: главная страница

Задачи: T-003 (главная), T-005 (Video), T-006 (Game dev), T-007 (AI), T-004 (кейс).
Файлы: `home.html` — макет; снимки `home-390.png`, `home-1280.png`, `home-1920.png`.
Тема одна — тёмная. Картинки — заглушки-градиенты; тексты — черновик на английском.

## Как это работает

- **Кто видит:** заказчик или агентство, пришедшие по ссылке из Telegram, резюме или переписки.
- **Первый экран:** кто Дамир (Video editor · AI developer · Game dev), одна фраза о том, что он делает, кнопки Telegram и почты, шоурил справа (на телефоне — под текстом), строка инструментов ИИ.
- **Ниже по порядку:** Selected work (3 лучшие работы) → Video (сетка роликов) → Websites (кейс Go Fashion + «новый проект в работе») → Game dev (скриншоты и что сделано / что дальше) → AI (Claude Code, ChatGPT, Higgsfield + обложки-превью) → How I work → контакты → подвал «сайт сделан мной с Claude Code».
- **Метки ИИ:** оранжевые метки на работах, где использовался ИИ.
- **Видео:** по нажатию ролик открывается во встроенном плеере стороннего видеохостинга; сам файл на сайте не лежит.
- **Мало работ в разделе:** раздел показывает сколько есть; пустой раздел скрывается целиком.
- **Много работ:** в разделе Video — 6 лучших, остальные по кнопке «More videos».
- **Не делаем:** блог, форму обратной связи, русскую версию, светлую тему, LinkedIn.
