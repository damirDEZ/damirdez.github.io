# Макет: иконка сайта и карточка ссылки

Задача: T-008. Файлы: `og.html` — макет; снимок `og-1360.png`.
Строится на дизайн-системе (цвета, Space Grotesk, градиенты-заглушки).

## Как это работает

- **Карточка ссылки (1200×630)** — картинка, которую мессенджеры и соцсети показывают под ссылкой на сайт. Повторяет первый экран: логотип, Telegram, главная фраза, роли, три кадра — сайт, ИИ-фильм, игра. Когда будут настоящие работы — в кадрах их картинки.
- **У страницы кейса** своя карточка: название работы и её обложка (тот же шаблон, генерируется при сборке).
- **Иконка** — «D.» с оранжевой точкой на тёмном квадрате со скруглением; видна на вкладке браузера (16/32) и на экране телефона, если сайт добавить на главный экран (180).
- **Заголовок и описание ссылки** — из title и description страницы (английский).
- **Не делаем:** анимированную иконку, отдельные карточки под каждую соцсеть.
