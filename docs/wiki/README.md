# Техническая документация

Оглавление подсистем: одна строка и ссылка.

- [Карта файлов](repository.md) — где что лежит.
- [Сайт](site.md) — каркас на Astro, шапка и подвал, команды, снимки экрана, выкладка на GitHub Pages и её переменные.
- [Главная](home.md) — разделы главной, где лежат тексты и работы (`src/data/`), как заменить заглушки реальными работами.
- [Страница кейса](case.md) — шаблон `/work/<slug>/`, поля данных кейса (`src/data/cases.ts`), «Next work», как добавить кейс и заменить заглушки Go Fashion.
- [Карточка ссылки и иконки](seo.md) — meta-теги для мессенджеров, карточки 1200×630 и иконки сайта: откуда берутся, как и когда перерисовать (`npm run og`, `npm run icons`).
