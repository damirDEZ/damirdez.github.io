# Сайт-портфолио — правила проекта

Главный файл правил для всех агентов и людей. `CLAUDE.md` ссылается сюда.

## 1. С чего начинать

- Роадмап (единственный источник задач): `docs/roadmap/roadmap.toml`
- Состояние менеджера и передача дел: `docs/roadmap/handoff.md`
- Техническая документация: `docs/wiki/README.md`, карта файлов: `docs/wiki/repository.md`
- Записи решений «почему так»: `docs/adr/`
- Дизайн-система: `docs/design/system.md`, токены — `src/styles/tokens.css`, витрина — `docs/design/system.html`
- Как устроен сайт, как собрать и снять снимки: `docs/wiki/site.md`
- Известные проблемы: `docs/known-issues.md`
- Скилл менеджера: `.claude/skills/project-manager/` (только локально, в git не входит)

## 2. Как работаем

- **Менеджер** — отдельный чат «Менеджер». Код продукта не пишет: правит роадмап, правила, документацию, рисует макеты, запускает и принимает работу исполнителей.
- **Исполнитель** — один чат на одну задачу, название чата «T-NNN: коротко».
- Найденное по дороге — новая задача через менеджера, а не правка «заодно».
- Чужие задачи не брать. Новые номера задач занимает только менеджер.

## 3. Готовность

- «Готово» = выкачено и проверено автоматически (тесты, снимки экранов на живом сайте).
- Статусы: Planned → In Progress → Auto Check → (Manual Check) → Completed; отдельно Needs Owner · Blocked · Deferred.
- Видимое посетителю идёт в работу только после «да» владельца на макет.

## 4. Владелец

- Имя: Дамир.
- Общение — коротко и простым языком, без жаргона, путей к файлам и номеров коммитов.
- Решает только владелец: деньги сверх потолка, крупные перемены того, что видит посетитель, необратимое (домены, удаление), аккаунты, ключи, оплата сервисов.
- Решения владельца записываем с датой и именем: «Имя 24.11: …».

## 5. Правила, которые легко нарушить

Пополнять, как только что-то сломалось: правило + причина.

- Секреты (ключи, пароли, токены) не храним в репозитории и не печатаем в чат.
- **Репозиторий открытый** (нужно для бесплатного GitHub Pages): всё, что в git, видят все. Скилл менеджера `.claude/skills/` в git не входит (может быть чужим материалом) — лежит только локально. Новые папки с личным или чужим — сразу в `.gitignore`.
- **CSS из макета не переносить один в один в стили компонентов Astro.** Astro добавляет атрибут области к каждой части селектора, и сила правил меняется (например, `div + div` начинает перебивать `:nth-child(3)`). Переносить — и сверять снимками с макетом. Найдено в T-004 (25.11).

## 6. Документация вместе с кодом

Задача не готова, пока страницы wiki, описывающие изменённый код, не обновлены — в той же ветке.

## 7. Проверки перед пушем

Обе команды — без ошибок (как устроены — `docs/wiki/site.md`):

- `npm run check` — свежесть карточек ссылки и иконок (упала «устарела» — `npm run og` / `npm run icons`, посмотреть картинки), проверка типов (`astro check`, падает и на предупреждениях) и сборка.
- `npm run shots` — сборка и снимки экрана 390, 1280 и 1920 px + 390 с открытым меню в `shots/`; падает при горизонтальной прокрутке, ошибках загрузки и JS, неработающем меню. Снимки посмотреть глазами. Тема одна — тёмная.
